    utils

    Static information and general utility functions for pypsa_validation_processing.

    MissingInputError

    Bases: Exception

    Raised by a statistics function when a required input key is missing.

    The message names the missing key (e.g. a dotted config path such as sector.district_heating.district_heating_loss). Network_Processor catches it and skips the variable for that network.

    create_location_index_from_copperplate(raw_input: pd.Series | pd.DataFrame, usage_location_list: list, column_name: str = 'location')

    Replace the values of level column_name of an indexed object. Default column_name to be replaced is "location" for backward compatibility.

    This helper rebuilds the index of raw_input from its index frame and overwrites the column_name column with values from usage_location_list. It is mainly used when location information from a copperplate-carrier result must be mapped back to explicit regional labels.

    		 required
    usage_location_list list

    		 required
    column_name str

    Name of the index level to replace, by default "location".

    		 'location'

    Returns:

    Type Description
    Series or DataFrame

    A copy of raw_input with the same data and a rebuilt index where the column_name level has been replaced.

    Raises:

    Type Description

    ValueError

    attribute_locations(n: pypsa.Network, flows: pd.Series | pd.DataFrame) -> pd.Series | pd.DataFrame

    Attribute flows on copperplate buses to a location (D1).

    pypsa.statistics already attributes a flow to the location of the bus at the evaluated port (D1.1, D1.2). This helper applies the copperplate exception: a Link flow at location EU is moved to the location of the Link's bus1 (D1.3). If bus1 is a copperplate bus as well, the flow stays at EU (D1.4). Flows of other components are not changed.

    Parameters:

    Name Type Description Default
    n Network

    Network the flows were evaluated on.

    		 required
    flows Series | DataFrame

    Result of a pypsa.statistics call whose index contains the levels component, name and location. pypsa.statistics drops the component level if components is a single string, so pass a list (e.g. components=["Link"]).

    		 required

    Returns:

    Type Description
    Series | DataFrame

    Copy of flows with the location level replaced. Rows are not regrouped, so two rows may now share all index values.

    Raises:

    Type Description
    ValueError

    If the index of flows lacks one of the required levels.

    apply_domestic_share(energy_stats: pd.Series | pd.DataFrame, energy_totals: pd.DataFrame | None, kind: str) -> pd.Series | pd.DataFrame

    Multiply flows by the domestic share d_k(c) of their country (D4).

    d_k(c) = total domestic k / (total domestic k + total international k) with c = the first two characters of the location. The share is looked up only for rows with a non-zero value (in any snapshot); rows that are 0 everywhere stay 0 without a lookup, e.g. the pseudo-location EU.

    Parameters:

    Name Type Description Default
    energy_stats Series | DataFrame

    Energy statistics with a location index level; a DataFrame has snapshots as columns.

    		 required
    energy_totals DataFrame | None

    Energy totals of one year, indexed by country (C2.4).

    		 required
    kind str

    "aviation" or "navigation".

    		 required

    Returns:

    Type Description
    Series | DataFrame

    energy_stats multiplied row-wise by d_k; a denominator of 0 gives 0.

    Raises:

    Type Description
    ValueError

    If energy_totals is None or kind is not supported.
    MissingInputError

    If a row with non-zero Energy statistics belongs to a country without a row in energy_totals; Network_Processor then skips the variable.

    non_energy_use(demand: pd.Series | pd.DataFrame, shares: pd.DataFrame | None, carrier: str) -> pd.Series | pd.DataFrame

    Return the industrial non-energy use NE_x(l) (D5, Eurostat fallback).

    NE_x(l) = S[c, x] · demand(l) with c = the first two characters of the location and S the Eurostat shares (C2.5). A country without a row for carrier gets the unweighted mean of all rows of carrier, with one WARNING per call naming the countries (none for the copperplate EU). NE_H2 is 0, with one WARNING per call. 0 ≤ S ≤ 1 is checked when the file is read; a share outside [0, 1] here (e.g. after an adaptation of the shares) is clipped to [0, 1] with one WARNING per call, so 0 ≤ NE_x(l) ≤ demand(l).

    Parameters:

    Name Type Description Default
    demand Series | DataFrame

    Industry demand of carrier (e.g. the gas for industry Load) with a location index level; a DataFrame has snapshots as columns.

    		 required
    shares DataFrame | None

    Index (country, carrier), column non_energy_share (C2.5). Read from the CSV written by the sister package eurostat-energy-balance_processing (utils.calculate_industry_non_energy_shares, written by IAMC_Creator.write_industry_non_energy_shares).

    		 required
    carrier str

    "Natural Gas", "Oil", "Coal" or "H2".

    		 required

    Returns:

    Type Description
    Series | DataFrame

    Non-energy use with the index and columns of demand.

    Raises:

    Type Description
    ValueError

    If carrier is not supported, or shares is None for a carrier other than "H2".

    apply_coke_correction(coal_energy: pd.Series | pd.DataFrame, kappa: float | None = None) -> pd.Series | pd.DataFrame

    Apply the coke correction to the energy part of industrial coal (D6). PyPSA reports with coal for industry the coal, that goes into coke ovens, Eurostats final energy counts the coke, that comes out of them.

    FE = E · (1 − κ) + E · κ / MWH_COAL_PER_MWH_COKE with E the coal for industry demand minus its non-energy use (D5).

    Parameters:

    Name Type Description Default
    coal_energy Series | DataFrame

    Energy part E of the industrial coal demand.

    		 required
    kappa float | None

    Coke share κ in [0, 1] from the physical method (C2.5). If None (default), the Eurostat fallback κ = 0 applies and one WARNING is logged.

    		 None

    Returns:

    Type Description
    Series | DataFrame

    Coal final energy with the index and columns of coal_energy.

    Raises:

    Type Description
    ValueError

    If kappa is outside [0, 1].

    decentral_heat_split(n: pypsa.Network, aggregate_per_year: bool = True) -> pd.Series | pd.DataFrame

    Split the input to decentral heat supply between sectors (D8).

    For each bus carrier b of DECENTRAL_HEAT_BUS_CARRIERS and location l: D8_x(l) = Σ_b σ_b,x(l) · I_b(l). I_b is the withdrawal of the Links that supply heat to b at their non-heat input ports (location per D1), plus the heat supplied by Generators (solar thermal) and by CHPs (Links with a further non-heat output) to b. Heat storage and heat vents are excluded. σ_b,x are yearly demand shares, applied to every snapshot.

    Parameters:

    Name Type Description Default
    n Network

    Network to evaluate.

    		 required
    aggregate_per_year bool

    If True (default), return yearly values as a Series; otherwise a DataFrame with snapshots as columns.

    		 True

    Returns:

    Type Description
    Series | DataFrame

    Index levels sector (rc, agr, ind, other), location, carrier (input carrier) and unit (normalised to MWh, C6.5). Empty if no decentral heat bus is supplied.
